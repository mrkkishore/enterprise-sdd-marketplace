| 2 | Approved pack catalog | `enterprise/PACK-CATALOG.md` |

| 4 | Gate profile rule: data classification sets the minimum profile | EA-ADR-007 |

EA touchpoints per team: kickoff · slice plan review · ADR/exception approvals · quarterly pack review.
