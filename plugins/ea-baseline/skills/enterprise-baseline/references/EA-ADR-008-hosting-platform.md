# EA-ADR-008: Application hosting platform
- Status: Proposed — DECISION PENDING
- Options under evaluation: Red Hat OpenShift · Amazon EKS · AWS Lambda (serverless)
## Interim rule
Until this ADR is Accepted, each project records its platform choice as a project ADR that cites this one, and the choice needs an EA `framework-decision` approval. Packs exist or are planned per option (see PACK-CATALOG.md).
## Decision criteria
Intranet-only exposure, Oracle connectivity, operational model and skills, cost, existing landing zones, compliance.
